# مساعد الدراسة على تيليجرام

بوت يقرأ تسجيلًا صوتيًا أو PDF أو صورة أو نص، ثم يعطيك ملخصًا وأسئلة وبطاقات مذاكرة.

## التشغيل محليًا

1. ثبّت Python 3.10 أو أحدث.
2. انسخ `.env.example` إلى `.env` وضع مفاتيح تيليجرام وGemini.
3. ثبّت المكتبات وشغّل البوت:

```bash
pip install -r requirements.txt
python bot.py
```

4. افتح تيليجرام وأرسل `/start`.

الملفات الأكبر من حوالي 19MB لا يقدر البوت يحملها بسبب حد تيليجرام.
